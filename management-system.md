# Meeting Cadence

## Biweekly Review

- Mobills:
  - Review and add last 2 weeks incomes and expenses
  - Export transactions and add to `data/` folder
- KPIs:
  - Check KPIs and inspect most actionable categories
    - Actuals x budget diluting
    - Actuals x budget not diluting
    - Actuals x budget removing diluted expenses
  - Check any transaction in Unknown category
  - Check KPIs for other categories

## Monthly Review

- Monthly view:

  - For last 3 months, check all charts with dilution
    - Goal: identify anomalies
  - For last 3 months, check all charts without dilution

  - For this year, check all charts without dilution
